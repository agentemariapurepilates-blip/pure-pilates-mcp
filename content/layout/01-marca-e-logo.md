# Marca e Logo — Pure Pilates

## Composição do logo

O logotipo é formado por dois elementos inseparáveis em conjunto, mas o ícone pode aparecer sozinho:

1. **Ícone** — silhueta de uma mulher fazendo pilates (com bolinha/cabeça vermelha)
2. **Naming** — "Pure" (em vermelho, peso bold arredondado) + "PILATES" (em cinza escuro, tipografia leve, letras espaçadas, abaixo de "Pure")

## Versões permitidas

| Versão | Quando usar |
|---|---|
| **Positiva** (cores oficiais sobre fundo claro) | Padrão. Use sempre que possível |
| **Negativa preferencial** (Pure vermelho + Pilates branco + ícone branco sobre fundo escuro) | Fundos pretos, cinza escuro, vermelho |
| **Grayscale 100% preto** (sobre fundo claro) | Materiais sem cor (jornal, fax, gravação) |
| **Grayscale 75% preto** (sobre cinza claro) | Quando 100% preto destoa do fundo |
| **Branco 100%** (sobre fundo escuro) | Quando não pode usar a versão preferencial negativa |
| **Versão terciária — vermelho monocromático** | Aplicações de uma cor só, sobre fundo claro |
| **Versão terciária — cinza monocromático** | Aplicações de uma cor só, sobre fundo claro |
| **Versão terciária — branca sobre vermelho** | Sobre o vermelho oficial da marca (`#C12030`) |
| **Versão terciária — branca sobre cinza escuro** | Sobre o cinza escuro oficial da marca (`#231F20`) |

## Área de proteção (clear space)

Sempre manter um espaço mínimo em volta do logo, livre de outros elementos. A distância mínima é equivalente à **altura da letra "P"** do naming, em todas as direções (cima, baixo, direita, esquerda).

## Redução mínima

| Aplicação | Tamanho mínimo |
|---|---|
| Logo completo (ícone + naming) na horizontal | **27 mm de largura** |
| Apenas o ícone (mulher) | **7 mm de altura** |

Abaixo desses tamanhos, a legibilidade e proporção se perdem. Para aplicações digitais, manter equivalência proporcional em pixels.

## O que NÃO fazer com o logo

NUNCA:

- Mudar a cor do logo para cores fora da paleta oficial (ex: azul, roxo, verde — proibido)
- Distorcer (esticar horizontal ou vertical, comprimir)
- Aplicar sombra, brilho, efeitos 3D, contorno
- Girar ou inclinar
- Usar sobre fundos confusos (fotos com muita textura no centro, fundos com ruído)
- Aplicar o logo dentro de formas/molduras decorativas
- Glow ou desfoque
- Separar os elementos (ex: usar só "Pure" sem o ícone e sem "PILATES" em contextos institucionais)
- Recortar partes do logo
- Sobrescrever com texto ou elementos
- Usar versão positiva (Pure vermelho + Pilates escuro) sobre fundo escuro — usar a versão negativa nesse caso
- Usar versão negativa (Pilates branco) sobre fundo claro — usar a positiva
