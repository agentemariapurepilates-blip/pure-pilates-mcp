# Grafismos e Ícones — Pure Pilates

## Estilo visual dos ícones

Os ícones da Pure Pilates seguem um sistema unificado:

- **Formas geométricas simples** dentro de **círculos** (preferencial) ou com contorno arredondado
- **Cor principal**: Vermelho Pure `#C12030` para o ícone ou contorno
- **Fundo do ícone**: branco, cinza escuro `#231F20` ou vermelho `#C12030` — sempre alto contraste
- **Estilo**: silhueta sólida (não outline fino), traços arredondados, sem detalhes excessivos
- **Nunca**: ícones em outline 3D, com sombras, com gradientes, em estilo cartoon ou fotorrealista

## Ícones do sistema oficial

Conjunto de ícones já estabelecidos no brand book — usar estes antes de criar novos:

| Ícone | Significado |
|---|---|
| **Círculo sólido vermelho** | Aulas / produto principal |
| **Coração vermelho** | Saúde / bem-estar / amor pelo método |
| **Cruz médica vermelha** | Saúde / cuidado / segurança |
| **Capelo de formatura vermelho** | Formação / capacitação / professores |
| **Etiqueta com %** | Promoções / planos de mensalidade |
| **Bolsa de compras** | Pure Store / produtos físicos |
| **Play (triângulo dentro de círculo)** | Vídeo / Pure Play / conteúdo audiovisual |
| **Pessoa + engrenagem** | Tech / Pure App / sistemas |

## Aparelhos de pilates como ícones

Quando comunicar aparelhos, usar as **formas geométricas oficiais** (não fotos):

- **+REFORMER** — forma retangular arredondada (paisagem)
- **+CHAIR** — forma pequena quadrada arredondada
- **+BARREL** — forma oval/cilíndrica horizontal
- **+CADILAC** — forma retangular vertical (retrato)
- **+SAÚDE** — bandeira retangular com cruz médica

Cor de fundo: cinza escuro `#231F20`. Elementos brancos. Detalhes em vermelho `#C12030`.

> Observação do brand book: **usar as figuras sem os textos** quando aplicado como grafismo decorativo. Os rótulos (+REFORMER etc.) são apenas para referência interna.

## Grafismos auxiliares (background)

Padrões visuais recorrentes que podem decorar peças:

- **Linhas concêntricas vermelhas** (efeito de "ondas" ou "trilhas") — usado como elemento decorativo em cantos e fundos
- **Pontilhado de pontos vermelhos** — preenchimento de áreas, transições, decoração
- **Semicírculo vermelho com gradiente** — elemento de canto, especialmente em peças com fundo vermelho ou cinza escuro
- **Roda de ícones em órbita** (círculo central + ícones dispostos em volta) — comunicação de ecossistema/serviços

## Aplicação em timeline / jornada

Para comunicar etapas, sequências ou jornada do aluno:

- Círculos com ícone dentro, alinhados horizontalmente, conectados por **linha vermelha**
- Cada círculo tem **borda vermelha** + ícone vermelho dentro
- Texto explicativo acima ou abaixo de cada círculo, em Montserrat Bold + Cinza escuro Pure `#231F20`

## O que NÃO fazer com grafismos

- Não criar ícones em estilos diferentes (flat com outline, 3D, isométrico)
- Não usar emojis em peças institucionais
- Não usar ícones de bibliotecas genéricas (Font Awesome, Material Icons puros) — adaptar pro estilo Pure
- Não combinar mais de 3 grafismos na mesma peça (poluição visual)
- Não usar cores fora da paleta nos ícones
